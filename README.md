## ⚙️ Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Samar-111/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npx next dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) to view your site locally.
